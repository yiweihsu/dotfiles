Custom coordinated themes for Ghostty, Claude Code, and Codex syntax highlighting.

- **Slow Sky**: sky-tinted paper, blue-gray ink, roasted-orange accent.
- **Matcha Milk**: matcha-tinted paper, green-gray ink, roasted-orange accent.

## Color rules

OKLCH controls perceptual lightness/chroma/hue. Canvas L=0.962; primary ink
L=0.30; secondary L=0.43; muted L=0.46. Accents share L=0.44, C=0.07–0.12.
The canvas uses very low chroma to keep large surfaces calm. Blue denotes
information, green success/additions, red errors/removals, amber caution,
purple secondary emphasis, and roasted orange the assistant/cursor accent.
These roles are shared across both themes.

The generator reduces chroma into the sRGB gamut, then checks the rounded hex
values using WCAG relative luminance. All 10 semantic text colors are checked
against seven relevant backgrounds (canvas, raised surface, selection, and
four diff surfaces), with a minimum 4.5:1 ratio. The divider against the canvas
must reach 3:1. Exact measurements are in `tokens-and-contrast.json`.
These measurements validate theme tokens, not every pixel produced by an app.

Ghostty `minimum-contrast = 1` disables automatic foreground recoloring;
contrast is checked offline instead. On Ghostty 1.3.1 native macOS glass sets
the renderer background alpha to zero. The text shader premultiplies that
background to black before its contrast check, which can turn dark text white
even though the visible glass surface is light. Both native glass and runtime
contrast recoloring are disabled for these light themes. `faint-opacity = 1`
prevents a second 50% fade.
The standard xterm 256-color cube is preserved. ANSI 0–15 are mapped to the
semantic palette; bright accents retain readable lightness on the light base.

Claude Code gets a custom theme based on its supported `light` preset, with
explicit text, message, diff, and status tokens. Codex uses its built-in
`catppuccin-latte` syntax theme, replacing the dark `zenburn` preference.
The Codex theme is a compatible built-in, not a custom exact palette match.

## Rebuild and switch

```sh
python3 ~/dotfiles/ghostty/design-system/build.py
python3 ~/dotfiles/ghostty/design-system/apply.py sky
python3 ~/dotfiles/ghostty/design-system/apply.py matcha
```

The switcher validates and reads back settings, backs up Ghostty and the prior
agent theme names under `~/.local/state/ghostty-themes/`, and requests Ghostty
reload through its official AppleScript action API. It preserves fonts,
shortcuts, running conversations, and all unrelated settings.

Running agent processes may cache themes. In Codex use `/theme` and select
Catppuccin Latte to update the current session. In Claude Code use `/theme`
and select Slow Sky or Matcha Milk. A newly created `~/.claude/themes/` folder
may require one Claude restart before custom themes are discovered. Do not
terminate active sessions to force a theme change.

The theme requests an opaque background without blur. On macOS, existing
windows may retain their previous background opacity until Ghostty restarts;
do not close running sessions to force that change. Disabling runtime contrast
recoloring and native glass does not require restarting conversations.

## Ube Milk (current, 2026-10-24)

Generated by `palettes.py` (also defines Oat Matcha, Koicha, 裏柳, 柳染, Ube).
Light ube surface `#f3ecff`, deep ube ink `#2a2238`, brand `#6b3fc4`;
`#aa77ff` is used only for non-text accents (cursor, prompt border). Every
text color is checked at >= 4.5:1 against canvas, surface, diff and selection
backgrounds. Active pieces: inline block in Ghostty `config`,
`~/.claude/themes/ube-milk.json` (`custom:ube-milk`), Codex `tui.theme = "base16-256"`
so Codex syntax follows the ANSI palette.
